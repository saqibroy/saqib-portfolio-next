## Production build shape

All content routes are prerendered:

- Static: home, work index, CV, notes index, metadata routes.
- Statically generated: three work case studies and two engineering notes.
- No AI, URL-fetching, audio, form-processing or other application API route ships.

The built-in Next bundle analyzer completed successfully. Reported first-load
uncompressed JavaScript was approximately:

- Home: 641.8 KiB, including the isolated Motion blueprint island.
- Other content routes: 520.4 KiB.

These are analyzer uncompressed module totals, not network transfer sizes. Motion is
not included by the non-home content routes, no WebGL dependency is present, and there
is no offscreen rendering loop.

## Security and privacy review

- Removed both POST APIs and their third-party model/service dependencies.
- Removed the arbitrary-URL accessibility-checker proxy and therefore its SSRF
  exposure from this application.
- Removed submitted-content logging paths, hardcoded model names and browser exposure
  of the TTS service variable.
- Added CSP, referrer policy, permissions policy, frame denial and MIME-sniffing
  protection.
- Retained no application secrets in the rebuilt runtime.
- `npm audit --omit=dev` reports 0 vulnerabilities after pinning patched PostCSS and
  Sharp versions over the versions bundled by the stable Next.js release.

## Deployment checklist

1. Review the local diff and factual questions.
2. Run `npm ci`.
3. Run `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`, and
   `npm run test:e2e`.
4. Deploy the production build to a Node.js host with Node 20.9 or newer.
5. Point the production domain to `https://ssohail.com`.
6. Verify `/opengraph-image`, `/robots.txt`, `/sitemap.xml`, and the CV PDF.
7. Verify Vercel Analytics and Speed Insights only if the selected host is Vercel.
8. Collect field Core Web Vitals before claiming 75th-percentile performance.
