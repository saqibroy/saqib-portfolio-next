# Phase Reports

Add one report for every completed phase or pull request.

Required sections:

1. scope and exit criteria;
2. inspected inputs;
3. decisions made;
4. files changed;
5. commands and results;
6. screenshots or visual notes;
7. accessibility/performance/security evidence;
8. trade-offs and unresolved risks;
9. tracker updates;
10. recommended next pull request.

Do not copy optimistic results from an earlier phase. Record the commands and
evidence from the actual implementation branch.
